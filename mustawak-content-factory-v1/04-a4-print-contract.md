# 04 — عقد Mustawak A4 Print v4.2

- الملف: `references/Mustawak_A4_Template_v4_2_Approved.html`
- الإصدار: `Mustawak A4 Summary Template v4.2`
- SHA-256: `2D981A49C06FE9412B1ACBE9A4753BC52384D5A1ACB655C510AC353AEA703E3C`
- المرجع محفوظ كما استلمه المصنع ولا يُعاد تصميمه من الصفر.

ملاحظة مرجعية: شريط المعاينة داخل الملف المرفق يعرض `v4.1` رغم أن اسم الملف والعنوان المعتمدين `v4.2`، كما أن وصف meta التجريبي يحتاج استبدالًا عند الإنتاج. في نسخة الفصل حدّث هذين النصين إلى بيانات الإصدار/المادة دون تغيير CSS أو الهوية، واترك المرجع المحفوظ كما هو.

الملف المرجعي يحتوي محتوى استعراضيًا فقط. عند إنتاج مادة يُستبدل المحتوى العلمي، مع الحفاظ على نظام التصميم والطباعة والمكونات.

## 2. الاستخدام الصحيح

- الناتج `summary.print.html` صفحة HTML كاملة مستقلة.
- لا ينتج المصنع PDF؛ يحوله المشرف من Chromium/Edge بعد المراجعة.
- لا ينسخ هذا الملف إلى `StudySummary.contentHtml`.
- بعد التحويل يرفع PDF عبر المسار المحمي المناسب، ثم يربط بالملخص في الإدارة.
- لا تُملأ أرقام `reviewPage` قبل اعتماد PDF النهائي.

## 3. ثوابت الهوية

حافظ على لوحة الألوان والخطوط والغلاف والعلامة والبطاقات والجداول والرسومات وكتل الكود والملاحظات والتعريفات والخلاصة. يبقى RTL افتراضيًا، وLTR للإنجليزية والكود، مع `print-color-adjust:exact`.

يمكن حذف مكون غير مطلوب، أو تكرار مكون مطلوب، أو تعديل ترتيب الأقسام. لا تُغيّر الهوية أو pagination الأساسية دون إصدار قالب جديد.

## 4. أوضاع اللغة

يضبط class على `<body>`:

- `language-ar-only`
- `language-en-only`
- `language-bilingual`

استخدم `.only-ar` و`.only-en` لإخفاء المحتوى غير المطلوب، و`.en` أو `.ltr` للمقاطع الإنجليزية. لا تستخدم `dir=ltr` على الصفحة كاملة لمجرد وجود مصطلحات إنجليزية.

## 5. التعريفات والإبراز

- عنوان التعريف (`.def-name`) أخضر وفق القالب.
- استخدم الأحمر فقط للكلمة الدالة أو الشرط أو الاستثناء الذي يحتاج تركيزًا.
- لا تلوّن الفقرة كلها، ويجب أن يبقى المعنى واضحًا دون لون.

## 6. المكونات المتاحة

اختر فقط ما يخدم المحتوى: `.definition`, `.panel`, `.note`, `.figure`, `.flow-map`, `.relationship-diagram`, `.steps`, `.table-wrap`, `.code-block`, `.summary-box`, `.tag-row`, `.facts`, `.three`, و`.mini`. لا تُفرض كلها في كل ملخص.

## 7. قواعد A4 ومنع القص

- الحجم A4، والغلاف يستخدم `@page cover` بهوامش صفرية، والمحتوى يستخدم `@page content`.
- لا تستخدم height ثابتًا أو `overflow:hidden` على صفحات المحتوى.
- اترك CSS fragmentation يوزع المحتوى، ولا تحاكِ صفحات A4 بصناديق ثابتة.
- `break-inside:avoid-page` مناسب للبطاقات القصيرة؛ أزله من المكون الطويل بدل إحداث فراغ كبير أو قص.
- الجداول الطويلة تنقسم بين الصفوف، وتمنع كسر الصف الواحد، وتكرر `<thead>`.
- code blocks تستخدم `white-space:pre-wrap` و`word-break:break-word`، وتنقسم إذا تجاوزت صفحة.
- تجنب grid/flex ضخمًا لا تستطيع محركات الطباعة تقسيمه.
- لا تعتمد على zoom لتصحيح overflow؛ أصلح المكون نفسه.

## 8. رابط MUSTAWAK.COM

استخدم رابط HTML فعليًا إلى `https://mustawak.com/` في الغلاف وfooter داخل document flow.

نص CSS داخل `@page` margin boxes ليس رابطًا قابلًا للنقر في PDF، لذلك يستخدم للوسم ورقم الصفحة فقط.

استخدم سمات الأمان `noopener noreferrer` للرابط الفعلي، واختبره في المتصفح وPDF الناتج.

## 9. إعدادات الطباعة

استخدم Chromium أو Edge: A4، scale 100%، background graphics مفعلة، وbrowser headers/footers معطلة.

## 10. فحص الطباعة

- افتح HTML بلا خادم وتأكد من عدم وجود طلبات شبكة غير متوقعة.
- افحص Print Preview صفحة صفحة: لا قص أو overlap أو صفحات بيضاء أو جداول مبتورة.
- اختبر تعريفًا وجدولًا طويلًا وكتلة كود وشكلًا ومحتوى ثنائي اللغة عند استخدامه.
- لا تعتمد `reviewPage` إلا بعد ثبات PDF النهائي.

## 11. الموارد

لا CDN أو JavaScript أو CSS خارجي. استخدم assets محلية أو data URI صغيرًا، ولا تضع signed URLs. لكل صورة نص بديل ومصدر مسجل.

## 12. الإصدار

لا تعدل المرجع المحفوظ؛ انسخه إلى الفصل باسم `summary.print.html` ثم استبدل المحتوى الاستعراضي. تعديل CSS أو الهوية يحتاج إصدار قالب جديد. سجّل `templateVersion: 4.2` وhash المرجع في release manifest.
