# 05 — عقد SEO الجامعي

## 1. الهدف

إنشاء بيانات موجزة ودقيقة تعكس الصفحة ومحتواها الفعلي، من دون حشو كلمات أو ادعاءات اعتماد أو تفوق غير مثبتة.

## 2. النطاق

يدعم النظام SEO للمالكين: university, college, major, subject, chapter, exam, study_summary، إضافة إلى المدونة. مصنع المادة يجهز عادةً Subject وChapter وStudySummary وQuiz. بيانات University/College/Major تُنتج مرة واحدة وتُراجع عند تغيرها.

## 3. قواعد العنوان والوصف

- `metaTitle` يصف الكيان والنية مباشرة، ولا يضيف `| مستواك` إذا كان النظام يضيف اسم الموقع.
- الحد التقني 160، لكن استهدف عنوانًا أقصر وواضحًا.
- `metaDescription` حتى 320، ويصف ما سيجده الطالب فعلًا.
- لا تذكر «رسمي»، «معتمد»، «شامل 100%»، أو وعود نتائج ما لم يثبتها مصدر وسياسة الموقع.
- `ogTitle` و`ogDescription` يمكن أن يكونا أكثر ملاءمة للمشاركة، مع بقاء المعنى نفسه.
- لا تكرر قائمة كلمات مفتاحية داخل الوصف.

## 4. Slug وCanonical

- `slug` يحدد في شاشة المالك، وليس داخل ملف SEO import.
- يسمح بحروف Unicode وأرقام وشرطة، دون مسافات، حتى 190.
- للـlocale الإنجليزي يفضل ASCII lowercase، مع مراعاة استثناءات الكود الحالية لبعض المالكين.
- لا تخترع canonical قبل معرفة المسار العام النهائي.
- أثناء الإنتاج اجعل `canonicalUrl` فارغًا و`noindex=true`.
- عند الاعتماد، استخدم URL مطلقًا يبدأ بـ`https://mustawak.com/` ويطابق الصفحة canonical الفعلية، بلا query tracking.

## 5. سياسة الفهرسة

- المسودة والتجربة: `noindex=true`, `nofollow=false` عادةً.
- لا تحول `noindex` إلى false إلا بعد نشر الكيان، صلاحية الصفحة، اكتمال المحتوى، وثبات canonical.
- `nofollow` لا يستخدم لإخفاء المسودات.
- القرار يكون لكل SeoMeta، وليس تلقائيًا من المصنع.

## 6. OG Image

- رابط HTTP/HTTPS مطلق فقط، حتى 500 حرف.
- لا تستخدم signed URL أو مسارًا محليًا.
- اتركه null إذا لم توجد صورة عامة نهائية.

## 7. Schema JSON-LD

- اختياري، ولا يُنتج لمجرد ملء الحقل.
- يجب أن يطابق الصفحة المرئية والكيان الحقيقي.
- لا تضف ratings أو author أو provider أو offers غير موجودة.
- الحد 64KB، العمق 20، وعدد nodes 2000.
- إذا لم يمكن التحقق من نوع schema وحقوله، استخدم null.

## 8. استيراد SEO الحالي

ملف الاستيراد سجل JSON واحد فقط. الحقول الوحيدة المقبولة:

`metaTitle`, `metaDescription`, `ogTitle`, `ogDescription`, `ogImageUrl`, `canonicalUrl`, `noindex`, `nofollow`, `schemaJson`.

لا تضف ownerType أو ownerId أو locale أو slug إلى JSON؛ اخترها في الواجهة قبل الاستيراد. أي حقل غير مدعوم يسبب رفض الملف.

## 9. استراتيجية الكيانات الجامعية

- University: الاسم، الدولة/النوع عند الحاجة، وما توفره الصفحة فعلًا.
- College: اسم الكلية والجامعة والتخصصات التابعة، دون counts غير معروضة.
- Major: اسم التخصص والجامعة/الكلية وسياق المواد.
- Subject: اسم المادة والتخصص والفصول/الملخصات الموجودة فعلًا.
- Chapter: اسم الفصل والمادة ونطاقه التعليمي.
- StudySummary: موضوع الملخص وطريقة الوصول إلى المحتوى.
- Quiz (`ownerType=exam`): نطاق الاختبار التدريبي، دون ادعاء أنه اختبار رسمي.

## 10. حقول التخطيط المحلية

يمكن حفظ primaryKeyword وsecondaryKeywords وsearchIntent وcanonicalStatus محليًا، لكنها ليست حقول import ولا تُرسل إلى قاعدة البيانات.

## 11. بوابة SEO

PASS يتطلب: حدود الحقول سليمة، URL صالح، تطابق العنوان والوصف مع الصفحة، لا claims غير مثبتة، لا field زائد، JSON-LD صالح إن وجد، وحالة noindex/canonical مناسبة لمرحلة النشر.
