# Mustawak Content Factory v1

حزمة تشغيل محلية لإنتاج المحتوى الجامعي في مستواك من مصادر معتمدة، ثم مراجعته وتجهيز حقوله للنسخ إلى لوحة الإدارة.

## الحدود

- هذه الحزمة مواصفات وقوالب فقط؛ لا تعدل كود الموقع أو قاعدة البيانات.
- المصدر العلمي الوحيد هو الملفات المدرجة في `source-manifest.csv` والمعلّمة `approved`.
- لا تُستكمل معلومة ناقصة من الذاكرة أو الإنترنت دون موافقة صريحة وإضافتها إلى سجل المصادر.
- المخرجات النهائية نوعان منفصلان:
  - `print_attachment`: ملف HTML كامل وفق قالب Mustawak A4 v4.2، يحوله المشرف يدويًا إلى PDF.
  - `platform_html`: مقطع HTML فقط لحقل `StudySummary.contentHtml`، بلا صفحة كاملة أو CSS أو JavaScript.
- الأسئلة المدعومة للاستيراد الجماعي حاليًا: `multiple_choice` و`true_false` فقط.
- كل MCQ منتج بواسطة المصنع يملك أربعة خيارات افتراضيًا وإجابة صحيحة واحدة فقط.

## طريقة التنظيم الموصى بها

اختر التنظيم حسب حجم المادة، ولا تنشئ محادثات بلا حاجة:

1. مادة صغيرة أو تجريبية: مشروع ChatGPT للتخصص، ومحادثة إنتاج واحدة لكل مادة.
2. مادة متوسطة/كبيرة أو كثيرة المصادر: مشروع مستقل للمادة، ومحادثة إنتاج رئيسية واحدة.
3. افتح محادثة تدقيق مستقلة عند بوابة الإصدار فقط؛ لا تقسّم كل فصل إلى محادثات متعددة تلقائيًا.
4. إذا طال السياق، ابدأ محادثة متابعة بعد تزويدها بـ`production-ledger.yaml` وآخر `release-manifest.yaml`، لا بالاعتماد على ذاكرة المحادثة.
5. يمكن استخدام GPT خاص موجود لتوحيد تعليمات البدء، لكنه ليس مصدر الحقيقة ولا مخزن المصادر أو الإصدارات.

## بنية الأرشيف المحلي للمادة

```text
<major>/
  <subject>/
    00-subject/
      subject-brief.yaml
      source-manifest.csv
      production-ledger.yaml
    01-chapters/
      01-<chapter-slug>/
        sources/
        chapter-package.md
        summary.platform.html
        summary.print.html
        questions.import.json
        quiz-data.md
        seo.summary.json
        seo.quiz.json
        qa-report.md
        release-manifest.yaml
```

استخدم أسماء مجلدات ASCII ثابتة، ولا تضع ملفات أسرار أو نسخًا غير معتمدة داخل مجلد الإصدار النهائي.

## ترتيب الاستخدام

1. اقرأ `00-operating-contract.md`.
2. املأ `templates/subject-brief.yaml` و`templates/source-manifest.csv`.
3. اعتمد تخطيط المادة كاملًا قبل إنتاج أول فصل.
4. استخدم `mustawak-spec-bundle.md` في تعليمات مشروع ChatGPT أو المحادثة.
5. اطلب: «نفّذ الفصل التالي كاملًا وفق الحزمة والمصادر المعتمدة».
6. نفّذ تدقيقًا مستقلًا وفق `06-quality-release-gates.md`.
7. انسخ الحقول إلى لوحة الإدارة بالترتيب الموجود في `templates/chapter-package.md`.
8. ابدأ كل سجل في حالة `draft`، ولا تنشره قبل اجتياز بوابة الإصدار.

## فهرس الملفات

| `03-question-quiz-contract.md` | سياسة الأسئلة والاختبارات وصيغة الاستيراد. |
| `04-a4-print-contract.md` | عقد استخدام قالب A4 v4.2 والطباعة. |
| `05-university-seo-contract.md` | سياسة SEO الجامعية وصيغة الاستيراد. |
| `06-quality-release-gates.md` | بوابات الجودة والتدقيق المستقل. |

## مصدر الحقيقة

عند التعارض تكون الأولوية:

1. كود مستواك الحالي وValidation الفعلي.
2. قرارات المنتج المعتمدة في العقود `00` إلى `06`.
3. بطاقة المادة وسجل المصادر.
4. القوالب القديمة، للاستفادة الاختيارية فقط.
