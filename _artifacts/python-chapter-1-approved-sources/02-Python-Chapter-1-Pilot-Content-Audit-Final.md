## 1. أمثلة `type()` توحي بإظهار النتيجة تلقائيًا

**التصنيف:** خطأ تقني
**الموضع:** قسم «معرفة النوع باستخدام type()»

الصيغة الحالية تعرض:

```python
age = 15
type(age)
```

ثم تقول إن النتيجة هي `<class 'int'>`.

هذا صحيح داخل **Interactive Shell**؛ إذ يعرض المفسر التفاعلي قيمة التعبير. أما عند تشغيل الكود من ملف Python، فإن استدعاء `type(age)` وحده لا يعرض شيئًا. يلزم استخدام `print(type(age))`، أو توضيح أن المثال ينفذ داخل المفسر التفاعلي. يميز توثيق Python الرسمي بين الأوامر التفاعلية وتشغيل ملف، كما يوضح أن `print()` هي التي تكتب القيمة عند تنفيذ Script.

### التصحيح الإلزامي

الأفضل للمبتدئ تعديل الأمثلة إلى:

```python
age = 15
print(type(age))
```

وتعديل بقية أمثلة الأنواع بالطريقة نفسها، دون تقديم شرح موسع لـ`print()`.

تضاف جملة قصيرة:

> نستخدم `print()` هنا لإظهار نتيجة `type()` عند تشغيل الكود من ملف Python.

يعدّل أيضًا التمرين الخامس إلى:

> استخدم `print(type(...))` لإظهار نوع كل قيمة عند تشغيل الكود من ملف.

## 2. وصف `int()` عند تحويل `float` يحتاج صياغة أدق

**التصنيف:** خطأ تقني
**الموضع:** «التحويل إلى int»

الصياغة الحالية:

> يزيل الجزء العشري في هذه الحالة، ولا يقوم بالتقريب إلى أقرب عدد.

صحيحة للمثال الموجب `1.62`، لكنها ليست الصياغة العلمية الأدق للسلوك العام.

توثيق Python ينص على أن تحويل العدد العشري باستخدام `int()` يقتطع الجزء الكسري **باتجاه الصفر**؛ لذلك `int(7.9)` يساوي `7`، و`int(-7.9)` يساوي `-7`.

### التصحيح الإلزامي

تستبدل الجملة بـ:

> تكون النتيجة `1`؛ لأن `int()` يقتطع الجزء الكسري باتجاه الصفر، ولا يقرّب القيمة إلى أقرب عدد صحيح.

لا يلزم إضافة مثال سالب في هذا الفصل، لكنه ممكن بوصفه تنبيهًا مختصرًا.

## 4. كتل الكود لا تحدد اتجاه LTR

**التصنيف:** مشكلة HTML أو RTL
**الموضع:** جميع وسوم `pre`

داخل صفحة عربية RTL قد تظهر علامات الإسناد والاقتباس وترتيب الأسطر بصورة مربكة إذا ورثت كتل الكود اتجاه الصفحة.

### التصحيح الإلزامي

يستخدم في جميع كتل الكود:

```html
<pre dir="ltr"><code>age = 15</code></pre>
```

لا يحتاج ذلك إلى `style=""` أو Class إضافية.

إذا كانت واجهة المنصة تفرض LTR على `pre` و`code` من خلال CSS العام، فيجب تأكيد ذلك أثناء تجربة الإدخال. يجب تطبيق أحد الحلين، لا ترك الاتجاه غير محسوم.

## أسماء المتغيرات والكلمات المحجوزة

الشرح صحيح:

* يمكن أن يحتوي الاسم على حروف وأرقام وشرطة سفلية.
* لا يبدأ برقم.
* لا يحتوي على مسافة.
* لا يستخدم Keyword مثل `class`.
* حالة الأحرف مهمة؛ لذلك `age` و`Age` اسمان مختلفان.

Python تسمح أيضًا بحروف Unicode في الأسماء، ومنها الحروف العربية، لكن عدم التوسع في ذلك مناسب للمبتدئ ولأسلوب كتابة كود قابل للقراءة على نطاق واسع. الكلمات المحجوزة لا تستخدم كأسماء عادية، ويجب كتابتها بحالتها المحددة.

مثال:

```python
student_name = سارة
```

صحيح نحويًا من ناحية كون `سارة` اسمًا ممكنًا، لكنه يعامل كاسم متغير لا كنص. وإذا لم يُعرّف هذا الاسم فسيظهر خطأ اسم غير معرّف. صياغة الملخص الحالية صحيحة، ويمكن إضافة عبارة «وإذا لم يكن الاسم معرّفًا فسيظهر خطأ» بوصفها تحسينًا.

## الأنواع الأساسية

شرح الأنواع صحيح:

| النوع      | حكم التدقيق                   |
| ---------- | ----------------------------- |
| `int`      | صحيح                          |
| `float`    | صحيح                          |
| `str`      | صحيح                          |
| `bool`     | صحيح                          |
| `None`     | صحيح                          |
| `NoneType` | صحيح عند استخدام `type(None)` |

النص `"15"` من نوع `str`، والقيمة `15.0` من نوع `float`، و`True` و`False` هما القيمتان المنطقيتان. كما أن `type()` باستدعاء ذي وسيط واحد يعيد كائن النوع الخاص بالقيمة.

## التحويلات

| التحويل          | حكم التدقيق                              |
| ---------------- | ---------------------------------------- |
| `int("15")`      | صحيح                                     |
| `int(1.62)`      | صحيح، مع تعديل وصف الاقتطاع باتجاه الصفر |
| `float("12.5")`  | صحيح                                     |
| `float(3)`       | صحيح، والنتيجة `3.0`                     |
| `str(15)`        | صحيح                                     |
| `str(True)`      | صحيح، والنتيجة `"True"`                  |
| `bool(0)`        | `False`                                  |
| `bool(1)`        | `True`                                   |
| `bool("")`       | `False`                                  |
| `bool("Python")` | `True`                                   |
| `bool("False")`  | `True` لأن النص غير فارغ                 |
| `int("12.5")`    | لا ينجح بوصفه نصًا عشريًا مباشرًا        |

الأعداد الصفرية والسلاسل الفارغة تعد False في اختبار القيمة المنطقية، بينما النصوص غير الفارغة تعد True بصرف النظر عن الكلمات المكتوبة داخلها.
