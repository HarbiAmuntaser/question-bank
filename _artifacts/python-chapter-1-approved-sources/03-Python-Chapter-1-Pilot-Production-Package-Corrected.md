# 3. تعديلات StudySummary وcontentHtml

## 3.1 بداية contentHtml

يُحذف عنصر `h1` الداخلي نهائيًا.

يبدأ `contentHtml` بالمقدمة مباشرة:

```html
<p>تحتاج البرامج إلى الاحتفاظ بالمعلومات حتى تتمكن من استخدامها لاحقًا. قد تكون هذه المعلومات اسم متعلم، أو عمرًا، أو طولًا، أو حالة منطقية توضح ما إذا كان المستخدم مبتدئًا. في Python نستخدم المتغيرات لإعطاء هذه القيم أسماء واضحة، بينما يحدد نوع البيانات طبيعة كل قيمة والطريقة المناسبة للتعامل معها.</p>

<h2>أهداف التعلم</h2>
```

عنوان الصفحة محفوظ في حقل:

> ملخص المتغيرات وأنواع البيانات في Python

ويدعم بدء `contentHtml` بعناوين `h2` بنية HTML البسيطة المعتمدة للملخصات.

---

## 3.2 اتجاه كتل الكود

تُعدّل جميع كتل `pre` في المحتوى إلى الصيغة:

```html
<pre dir="ltr"><code>age = 15</code></pre>
```

تطبق القاعدة على **كل** كتل الكود دون استثناء.

لا تضاف:

* خصائص `style`.
* Classes.
* `class="language-python"`.
* وسوم معقدة.

---

## 3.3 قسم type() المصحح

يستبدل قسم «معرفة النوع باستخدام type()» بالنص التالي:

```html
<h2>معرفة النوع باستخدام type()</h2>

<p>تعيد الدالة <code>type()</code> نوع القيمة أو المتغير.</p>

<p>نستخدم <code>print()</code> هنا لإظهار نتيجة <code>type()</code> عند تشغيل الكود من ملف Python.</p>

<pre dir="ltr"><code>age = 15
print(type(age))</code></pre>

<p>تظهر النتيجة:</p>

<pre dir="ltr"><code>&lt;class 'int'&gt;</code></pre>

<p>أمثلة أخرى:</p>

<pre dir="ltr"><code>height = 1.62
print(type(height))

student_name = "سارة"
print(type(student_name))

is_beginner = True
print(type(is_beginner))

notes = None
print(type(notes))</code></pre>

<p>تظهر الأنواع <code>float</code> و<code>str</code> و<code>bool</code> و<code>NoneType</code> بالترتيب.</p>
```

لا يقدم هذا القسم شرحًا موسعًا لـ`print()`؛ استخدامها هنا مقصور على عرض نتيجة `type()`.

## 3.4 وصف تحويل float باستخدام int()


```html
<p>تكون النتيجة <code>1</code>؛ لأن <code>int()</code> يقتطع الجزء الكسري باتجاه الصفر، ولا يقرّب القيمة إلى أقرب عدد صحيح.</p>
```

## السؤال 18 — تعديل اسم المتغير والسؤال

**questionText:** ما القيمة النهائية للمتغير `result`؟

```text
value = "0"
value = int(value)
result = bool(value)
```

**questionType:** `multiple_choice`
**difficultyLevel:** `hard`
**points:** 1

**options:**

1. النص `"False"`
2. القيمة `None`
3. القيمة المنطقية `False`
4. القيمة المنطقية `True`

**correctAnswer:** الخيار 3

**explanation:** يتحول النص `"0"` أولًا إلى العدد الصحيح `0`، ثم يحول `bool(0)` القيمة إلى `False`، وتُسند هذه القيمة إلى المتغير `result`.

**tags:** int، bool، تحويل الأنواع، قراءة الكود
**isActive:** `true`

## السؤال 20 — الاستبدال الكامل

**questionText:** بعد تنفيذ الكود التالي، يكون `age` من نوع `float`، بينما يبقى `Age` من نوع `str`.

```text
age = 15
Age = "15"
age = float(age)
```

**questionType:** `true_false`
**difficultyLevel:** `hard`
**points:** 1

**options:**

* صحيح
* خطأ

**tfAnswer:** `true`

**explanation:** تتعامل Python مع `age` و`Age` بوصفهما اسمين مختلفين لأن حالة الأحرف مهمة. تحولت قيمة `age` إلى `15.0` من نوع `float`، بينما بقيت قيمة `Age` هي النص `"15"` من نوع `str`.

**tags:** أسماء المتغيرات، float، str، قراءة الكود
**isActive:** `true`
