تحتاج البرامج إلى الاحتفاظ بالمعلومات حتى تتمكن من استخدامها لاحقًا. قد تكون هذه المعلومات اسم متعلم، أو عمرًا، أو طولًا، أو حالة منطقية توضح ما إذا كان المستخدم مبتدئًا. في Python نستخدم المتغيرات لإعطاء هذه القيم أسماء واضحة، بينما يحدد نوع البيانات طبيعة كل قيمة والطريقة المناسبة للتعامل معها.

أهداف التعلم

بعد دراسة هذا الملخص، يُتوقع أن تستطيع:

  • شرح معنى المتغير في Python.
  • استخدام علامة الإسناد لربط اسم بقيمة.
  • اختيار أسماء متغيرات صحيحة وواضحة.
  • التمييز بين الأنواع الأساسية: int وfloat وstr وbool.
  • فهم استخدام القيمة None.
  • استخدام type() لمعرفة نوع قيمة.
  • إجراء تحويلات أساسية باستخدام int() وfloat() وstr() وbool().
  • اكتشاف بعض الأخطاء الشائعة في الأسماء والتحويلات.

ما المتغير؟

المتغير اسم نستخدمه للإشارة إلى قيمة داخل البرنامج. يساعد الاسم الواضح على تذكر معنى القيمة واستخدامها في مواضع أخرى من الكود.

student_name = "سارة"
age = 15
height = 1.62
is_beginner = True

في المثال السابق:

  • student_name اسم متغير يشير إلى النص "سارة".
  • age اسم متغير يشير إلى العدد الصحيح 15.
  • height اسم متغير يشير إلى العدد العشري 1.62.
  • is_beginner اسم متغير يشير إلى القيمة المنطقية True.

الإسناد باستخدام علامة =

تسمى عملية ربط اسم المتغير بقيمة عملية الإسناد. تستخدم Python علامة = لتنفيذ الإسناد.

age = 15

تقرأ هذه العبارة بمعنى: أسند القيمة 15 إلى المتغير age. لا تعني العلامة هنا سؤالًا عن المساواة، بل تعني تخزين القيمة تحت اسم محدد.

اسم المتغير وقيمته

اسم المتغير ليس هو القيمة نفسها. في العبارة التالية:

student_name = "سارة"
  • student_name هو الاسم الذي نستخدمه داخل الكود.
  • "سارة" هي القيمة التي يشير إليها الاسم.

وجود علامتي الاقتباس حول "سارة" يعني أن القيمة نص، أما اسم المتغير فلا يوضع عادةً بين علامتي اقتباس.

إعادة إسناد قيمة جديدة

يمكن أن يشير المتغير إلى قيمة جديدة لاحقًا. تسمى هذه العملية إعادة الإسناد.

age = 15
age = 16

بعد تنفيذ السطر الثاني تصبح قيمة age هي 16. لا يحتاج البرنامج إلى إنشاء اسم جديد في كل مرة تتغير فيها القيمة.

يمكن كذلك أن يتغير نوع القيمة المرتبطة بالمتغير:

status = True
status = "مكتمل"

في السطر الأول يشير status إلى قيمة من نوع bool، ثم يشير في السطر الثاني إلى قيمة من نوع str. يكفي في هذا المستوى معرفة أن Python تسمح بإعادة إسناد قيمة من نوع مختلف، دون الدخول في تفاصيل الأنواع الديناميكية المتقدمة.

قواعد تسمية المتغيرات

يجب أن يلتزم اسم المتغير بعدد من القواعد الأساسية:

  • يمكن أن يحتوي على حروف وأرقام والشرطة السفلية _.
  • لا يجوز أن يبدأ برقم.
  • لا يجوز أن يحتوي على مسافة.
  • لا يجوز استخدام كلمة محجوزة في Python مثل class.
  • الأحرف الكبيرة والصغيرة مختلفة، لذلك age يختلف عن Age.

أسماء صحيحة

student_name = "سارة"
age2 = 16
course_status = "بدأ"
is_beginner = True

أسماء غير صحيحة

2age = 16
student name = "سارة"
class = "Python"

الاسم الأول يبدأ برقم، والثاني يحتوي على مسافة، والثالث يستخدم كلمة محجوزة.

اختيار اسم واضح

قد يكون الاسم القصير صالحًا، لكنه لا يكون دائمًا واضحًا. الاسم age أوضح من a عندما تمثل القيمة عمر المتعلم. تساعد الأسماء الواضحة على قراءة الكود ومراجعته.

أنواع البيانات الأساسية

النوع الاستخدام مثال
int الأعداد الصحيحة دون جزء عشري 15
float الأعداد التي تحتوي على جزء عشري 1.62
str النصوص والمحارف "سارة"
bool القيم المنطقية True أو False
None عدم وجود قيمة محددة حاليًا None

النوع int

يستخدم int للأعداد الصحيحة التي لا تحتوي على جزء عشري.

age = 15
completed_lessons = 3
temperature = -2

القيم 15 و3 و-2 كلها من نوع int.

النوع float

يستخدم float للأعداد التي تحتوي على جزء عشري.

height = 1.62
progress = 25.5
temperature = -2.5

وجود النقطة العشرية يجعل القيمة من نوع float، حتى عندما يكون الجزء العشري صفرًا، مثل 15.0.

النوع str

يستخدم str للنصوص. توضع القيمة النصية بين علامتي اقتباس مفردتين أو مزدوجتين.

student_name = "سارة"
course_name = 'Python'
age_text = "15"

القيمة "15" نص وليست عددًا؛ لأن وجود علامتي الاقتباس يجعلها من نوع str.

النوع bool

يستخدم bool لتمثيل حالتين منطقيتين فقط:

  • True
  • False
is_beginner = True
course_completed = False

يجب كتابة الحرف الأول كبيرًا. القيمتان true وfalse ليستا الصياغة الصحيحة للقيم المنطقية في Python.

القيمة None

تستخدم None عندما لا توجد قيمة محددة حاليًا.

final_result = None

لا تعني None العدد صفرًا، ولا تعني نصًا فارغًا، بل تمثل غياب قيمة محددة.

يمكن لاحقًا إسناد قيمة حقيقية إلى المتغير نفسه:

final_result = None
final_result = "ناجح"

معرفة النوع باستخدام type()

تعيد الدالة type() نوع القيمة أو المتغير.

نستخدم print() هنا لإظهار نتيجة type() عند تشغيل الكود من ملف Python.

age = 15
print(type(age))

تظهر النتيجة:

<class 'int'>

أمثلة أخرى:

height = 1.62
print(type(height))

student_name = "سارة"
print(type(student_name))

is_beginner = True
print(type(is_beginner))

notes = None
print(type(notes))

تظهر الأنواع float وstr وbool وNoneType بالترتيب.

التحويل بين الأنواع

يمكن استخدام دوال التحويل الأساسية لإنشاء قيمة من نوع جديد.

التحويل إلى int

age_text = "15"
age_number = int(age_text)

تصبح قيمة age_number عددًا صحيحًا من نوع int.

يمكن تحويل قيمة عشرية إلى عدد صحيح:

height = 1.62
whole_number = int(height)

تكون النتيجة 1؛ لأن int() يقتطع الجزء الكسري باتجاه الصفر، ولا يقرّب القيمة إلى أقرب عدد صحيح.

التحويل إلى float

price_text = "12.5"
price_number = float(price_text)

تصبح القيمة 12.5 من نوع float.

يمكن كذلك تحويل عدد صحيح إلى عدد عشري:

lesson_count = 3
lesson_count_float = float(lesson_count)

تصبح القيمة الجديدة 3.0.

التحويل إلى str

age = 15
age_text = str(age)

تصبح قيمة age_text هي النص "15".

كما يمكن تحويل القيم المنطقية:

status = True
status_text = str(status)

تصبح القيمة النصية "True".

التحويل إلى bool

يمكن استخدام bool() لتحويل قيم إلى قيمة منطقية.

print(bool(0))
print(bool(1))
print(bool(""))
print(bool("Python"))

النتائج بالترتيب:

  • False للعدد صفر.
  • True للعدد غير الصفري.
  • False للنص الفارغ.
  • True للنص غير الفارغ.

انتبه إلى أن:

print(bool("False"))

تعيد True؛ لأن القيمة نص غير فارغ، وليست القيمة المنطقية False.

أخطاء شائعة

البدء برقم في اسم المتغير

2age = 15

هذا الاسم غير صالح؛ لأن اسم المتغير لا يبدأ برقم.

نسيان علامات الاقتباس حول النص

student_name = سارة

ستتعامل Python مع سارة بوصفه اسمًا، لا قيمة نصية. الصياغة الصحيحة:

student_name = "سارة"

الخلط بين النص والعدد

age = "15"

القيمة هنا من نوع str وليست int.

تحويل نص غير مناسب إلى عدد

age = int("خمسة عشر")

لا يمكن لـint() تحويل هذا النص مباشرة إلى عدد صحيح؛ لأن النص لا يحتوي على أرقام مكتوبة بصيغة عددية مناسبة.

تحويل نص عشري مباشرة باستخدام int()

value = int("12.5")

هذا التحويل لا ينجح؛ لأن النص يمثل عددًا عشريًا. يمكن استخدام float("12.5") للحصول على قيمة عشرية.

تمارين قصيرة

  1. أنشئ متغيرًا باسم student_name وخزّن فيه اسمًا نصيًا.
  2. أنشئ متغيرًا باسم age وخزّن فيه عددًا صحيحًا.
  3. أنشئ متغيرًا باسم height وخزّن فيه عددًا عشريًا.
  4. أنشئ متغيرًا باسم is_beginner وخزّن فيه قيمة منطقية.
  5. استخدم print(type(...)) لإظهار نوع كل قيمة عند تشغيل الكود من ملف.
  6. حوّل النص "25" إلى عدد صحيح.
  7. حوّل العدد 25 إلى نص.
  8. صحح اسم المتغير غير الصالح 2student.
  9. توقع نتيجة bool(0) وbool("0")، ثم تحقق باستخدام بيئة Python.

مراجعة سريعة

  • المتغير اسم يشير إلى قيمة.
  • تستخدم علامة = للإسناد.
  • يمكن إعادة إسناد قيمة جديدة إلى المتغير.
  • لا يبدأ اسم المتغير برقم ولا يحتوي على مسافة.
  • int للأعداد الصحيحة.
  • float للأعداد العشرية.
  • str للنصوص.
  • bool للقيمتين True وFalse.
  • None تمثل عدم وجود قيمة محددة.
  • type() تساعد على معرفة نوع القيمة.
  • تستخدم int() وfloat() وstr() وbool() للتحويل الأساسي بين الأنواع.
