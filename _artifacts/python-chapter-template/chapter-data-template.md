# Chapter Data Template

استخدم هذا الجدول عند إنشاء فصل جديد من لوحة الإدارة. استبدل جميع placeholders قبل الإدخال.

| الحقل | القيمة | ملاحظة الإدخال |
| --- | --- | --- |
| Subject | `{{SUBJECT_NAME_OR_ID}}` | اختر مادة Python الصحيحة من لوحة الإدارة. |
| Chapter Name | `{{CHAPTER_NAME}}` | اسم عربي واضح يصف نطاق الفصل. |
| Chapter Number | `{{CHAPTER_NUMBER}}` | رقم صحيح ومتسلسل داخل المادة. |
| Description | `{{CHAPTER_DESCRIPTION}}` | وصف موجز لا يكرر محتوى الملخص كاملًا. |
| Learning Objectives | `{{LEARNING_OBJECTIVES}}` | قائمة أهداف محددة وقابلة للقياس. |
| isActive | `{{IS_ACTIVE}}` | استخدم `true` أو `false` حسب حالة الفصل. |

لا تضف SEO للفصل ما لم توجد له صفحة عامة مستقلة ومدعومة في النظام.
