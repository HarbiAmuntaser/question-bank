# Chapter Validation Checklist

## StudySummary HTML

- [ ] لا يوجد `h1` داخل `contentHtml`.
- [ ] يبدأ المحتوى بمقدمة مباشرة، ثم يستخدم `h2` للأقسام الرئيسية و`h3` للأقسام الفرعية.
- [ ] كل عناصر `pre` الخاصة بكود Python تحمل `dir="ltr"`.
- [ ] أسماء الدوال والأنواع والقيم والمعرّفات والعوامل التقنية المضمنة في الشرح تستخدم `<code>...</code>`.
- [ ] كل كود مستقل أو متعدد الأسطر يستخدم `<pre dir="ltr"><code>...</code></pre>`، وليس فقرة نصية عادية.
- [ ] HTML صالح ولا يحتوي على `script` أو `iframe` أو `style` أو inline styles غير معتمدة.
- [ ] أمثلة الكود قصيرة، قابلة للقراءة، وتختبر مفهومًا واحدًا قدر الإمكان.
- [ ] رابط الاختبار النسبي بصيغة `../quizzes/{quizSlug}` صحيح ويعمل.
- [ ] لا يوجد `h1` أو رابط أو محتوى مكرر من عنوان الصفحة الخارجي.

## Questions Admin Import

- [ ] ملف الأسئلة JSON صالح وجذره Array مباشرة.
- [ ] لا يحتوي الملف على `chapterId` أو `duplicateStrategy` أو `items` wrapper.
- [ ] كل كود Python مستقل أو متعدد الأسطر داخل `questionText` يستخدم fenced code مع language identifier بقيمة `python`.
- [ ] الدوال والمعرّفات والقيم والعوامل المضمنة داخل السؤال أو الخيار أو الشرح تستخدم inline backticks.
- [ ] لا يوجد كود متعدد الأسطر مخزن كنص عادي بعد فقرة السؤال.
- [ ] كل سؤال `multiple_choice` يحتوي خيارين على الأقل وإجابة صحيحة واحدة فقط.
- [ ] كل سؤال `true_false` يستخدم `tfAnswer` بقيمة Boolean: `true` أو `false`.
- [ ] جميع الأسئلة تحتوي `explanation` واضحًا وغير فارغ.
- [ ] كل `difficultyLevel` إحدى القيم: `easy` أو `medium` أو `hard`.
- [ ] كل `points` عدد صحيح موجب.
- [ ] Tags ضمن قاموس الفصل المعتمد ومتسقة في جميع الملفات.
- [ ] لا توجد أسئلة مكررة أو إجابات مبهمة.
- [ ] لا توجد مفاهيم تخص Chapters لاحقة.

## Visual Rendering Validation

- [ ] الأسئلة التي تحتوي كودًا تظهر ككتل كود منظمة في واجهة الطالب.
- [ ] لا يظهر أي كود متعدد الأسطر كفقرة نصية عادية.
- [ ] inline code يظهر بتنسيق واضح داخل الأسئلة والخيارات والشروحات.
- [ ] اتجاه كتل الكود وinline code هو LTR.
- [ ] يبقى النص العربي واتجاه الصفحة RTL.
- [ ] المصطلحات التقنية المضمنة في StudySummary تستخدم markup المعتمد `<code>`.
- [ ] كتل كود StudySummary تستخدم `<pre dir="ltr"><code>`.
- [ ] تمت مقارنة Student Preview مع Chapter 1 Reference Implementation.

## Data, SEO, And Release

- [ ] Chapter مرتبط بمادة Python الصحيحة ورقمه غير متعارض.
- [ ] StudySummary يبدأ بالحالة `draft`.
- [ ] يوجد `metaTitle` للملخص والاختبار، ولا يحتوي تكرارًا لاسم الموقع.
- [ ] يوجد `metaDescription` دقيق للملخص والاختبار.
- [ ] يوجد `ogTitle` مناسب للمشاركة الاجتماعية.
- [ ] يوجد `ogDescription` موجز ومناسب للمشاركة الاجتماعية.
- [ ] يبقى `canonicalUrl` بقيمة `null` أو فارغًا حتى اعتماد الرابط النهائي للصفحة.
- [ ] `noindex=true` للملخص والاختبار طوال مرحلة الإنتاج والتجربة.
- [ ] روابط المادة والملخص والاختبار الداخلية صحيحة.
- [ ] تم اختبار واجهة الطالب على الجوال وسطح المكتب.
- [ ] لم تُضف ادعاءات بأن المحتوى رسمي أو معتمد دون إثبات.
- [ ] لا توجد placeholders غير محسومة في HTML أو الجداول أو SEO أو JSON قبل النشر.
- [ ] لا يتم تغيير `noindex` أو حالة النشر إلا بعد اعتماد الفصل كاملًا.
